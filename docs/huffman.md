# Huffman coding
Huffman coding compresses characters of data into small byte sizes by how common they are.

## History
David A. Huffman published the algorithm in 1952.

## Sources
See [Huffman's original paper (1952)](https://doi.org/10.1109/JRPROC.1952.273898).
See [RFC 1951, sections 3.2.1 and 3.2.2](https://www.rfc-editor.org/rfc/rfc1951.html#section-3.2.1).
